## 📖 축적의 시간

> 플래닝과 피드백을 통해 어제보다 나은 오늘을 만드는 서비스

[서비스 URL](https://piled-time.com/) | [ERD](https://dbdiagram.io/d/piled-time-66ef68b7a0828f8aa69e84eb) | [Swagger](https://piled-time.com/api/swagger)

---

### 📌 프로젝트 개요

축적의 시간은 개인의 하루 일정을 직관적으로 기록하고, 주간·월간 단위로 데이터를 분석하여 더 나은 하루를 설계할 수 있도록 돕는 웹 서비스입니다.

#### 프로젝트 목적

- 오프라인 플래너의 통계·분석 한계 극복
- 기존 온라인 플래너의 시간 단위 부족 문제 보완
- 9년간의 플래너 사용 경험을 바탕으로 한 실제 사용성을 고려한 서비스 제작
- 1인 프로젝트로 기획, 디자인, 개발, 배포까지 전 과정을 직접 수행

#### 프로젝트 기간

- 2025.04 ~ 2025.08 (ver1)

---

### 🏗 아키텍처

아래는 서비스의 아키텍처 다이어그램입니다.

```
[Frontend: React]  →  [Backend API: NestJS]  →  [DB: MySQL]
           │                           │
           ▼                           ▼
     [AWS EC2 + Route53]        [Docker 컨테이너]
```

---

### 🛠 기술 스택

#### Frontend

- React, Axios, Zustand

#### Backend

- TypeScript, NestJS, TypeORM, MySQL, Swagger

#### DevOps

- Docker, GitHub Actions, AWS EC2, Route53

- 주간/월간 통계 분석 제공

### 향후 계획 ver2

- 캘린더 UI 및 일정등록 기능 추가
- 일기/자기 질문 기록을 인사이트로 구조화해 축적·검색·리뷰·행동 연결까지 지원하는 자기 성찰 모듈 추가
  - 기록하기: 프롬프트/자유일기/감정 스냅샷 중 선택 → 저장.
  - 자동 해석: 백엔드 워커가 감정·주제 태그, 요약, 가치/욕구 추출, 인사이트 후보 생성.
  - 인사이트 확정: 모델 제안안을 사용자가 편집/확정 → "인사이트 카드"로 축적.
  - 리뷰/패턴: 주간/월간 리뷰에서 반복 테마, 감정 패턴, 의미 변화 시각화.
  - 행동 연결: 인사이트별 미세 행동(실험) 제안 → 리마인드/체크인.
